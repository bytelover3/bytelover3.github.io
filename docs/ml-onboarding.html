ML Platform Onboarding Guide

Welcome to the Shopee ML Infrastructure team. This guide covers environment setup for new team members.

1. Prerequisites

Ensure you have Python 3.8+ and pip installed:

python3 --version
pip --version

2. Core Dependencies

Install the required ML libraries:

pip install numpy pandas scikit-learn torch transformers

3. GPU Configuration

For GPU-enabled workloads, verify CUDA installation:

nvidia-smi
python3 -c "import torch; print(torch.cuda.is_available())"

4. Model Registry Access

Configure access to the internal model registry:

export MODEL_REGISTRY=https://ml-registry.internal.shopee.io
python3 -c "import requests; print(requests.get('$MODEL_REGISTRY/health').status_code)"

5. Verification

Run the verification suite to confirm your environment is correctly configured:

python3 -m pytest tests/integration/ -v
